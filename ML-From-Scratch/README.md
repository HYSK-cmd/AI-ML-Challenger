# ML-From-Scratch

Machine learning models and algorithms implemented from scratch in NumPy.

- `mlfromscratch/` – the original library by [Erik Linder-Norén](https://github.com/eriklindernoren/ML-From-Scratch) (MIT)
- `mlfromscratch_mine/` – my own rewrites of the parts I implemented myself
  (activation/loss functions, regression, decision tree, KNN, LDA, naive Bayes, perceptron, utils)
- Files I rewrote were removed from `mlfromscratch/`, so the original package is no longer complete.

Setup: `pip install -r requirements.txt`
