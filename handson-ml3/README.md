# handson-ml3

My notebooks and exercises for *Hands-On Machine Learning with Scikit-Learn, Keras and TensorFlow* (3rd ed.)
by Aurélien Géron. Based on [ageron/handson-ml3](https://github.com/ageron/handson-ml3) (Apache-2.0).

- `Chapter*.ipynb` – my work, chapter by chapter
- `docker/` – Docker setup for JupyterLab (`docker compose up --build`, then open `localhost:8888`)
- `environment.yml` – conda environment (`homl3`)
- `start.ps1` / `start.sh` in `docker/` start the container and open JupyterLab
- Large model files (`*.pkl`, `*.pth`, `*.pt`) are stored with Git LFS.
