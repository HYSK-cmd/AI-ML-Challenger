# AI-ML-Challenger
My study repo for building ML and AI systems from scratch.

| Folder | What it is |
|---|---|
| [ML-From-Scratch](ML-From-Scratch) | Classic ML algorithms in NumPy, plus my own rewrites in `mlfromscratch_mine` |
| [handson-ml3](handson-ml3) | Notebooks and exercises from *Hands-On Machine Learning* (3rd ed.), with a Docker setup |
| [transformer](transformer) | A small GPT-style decoder-only LLM trained from scratch in PyTorch |

Each folder keeps the license of the work it builds on.
